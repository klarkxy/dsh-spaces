## 新电脑准备

```powershell
git clone https://github.com/klarkxy/dsh-spaces.git
cd dsh-spaces
git switch main
npm ci
pnpm run build:spaces
pnpm run typecheck
pnpm run typecheck:spaces
```

已有仓库则在确认本机无冲突改动后切到 `main` 并拉取。依赖安装暂沿用现有 `package-lock.json`，项目脚本可用 pnpm；本轮没有迁移锁文件。原机验证工具为 Node 24.21.0、pnpm 10.29.2。

插件安装见 [安装指南](../docs/plugin-standard-install.md)。`pnpm run dev` 启动 Electron 开发壳，不是 Web 插件入口。

真实浏览器验收前安装 Chromium：`pnpm exec playwright install chromium`。测试 CLI 用 `DSH_TEST_BIN` / `DSH_TEST_RC2_BIN` 指向新机实际官方 `bin.js`，`DSH_TEST_PNPM_CJS` 指向实际 pnpm 入口。`tests/compatible-dsh-cli.test.ts` 已去掉原机绝对路径：未设置可选集成测试变量时明确跳过，CI 安装真实 CLI 后显式执行。
