# Desktop 空间栏启动与快捷控制（2026-10-26）

用户指出：点击停止的空间只显示“请在设置中明确启动”，侧栏没有可见状态或启停右键菜单。

## 原因与结果

原侧栏被限定为只读展示导航，直接用缓存的运行状态拒绝停止空间。目录已有状态数据，但侧栏仅设置内部属性，未显示状态；已有右键管理菜单属于管理工作台，没有覆盖 Desktop 外层侧栏。正常的用户主动启动不受“禁止故障后自动恢复”限制。

本次把 Desktop 点击定义为显式打开操作：先读取当前状态，运行中直接进入，停止时提交一次启动，启动中观察已有启动；失败不重发。补充运行状态标识、状态提示与右键启动／关闭／重启，支持 Shift+F10、方向键和 Escape。启动后切回主应用时，迟到结果不会抢回界面；关闭或重启当前子空间时先回到保留的主应用。

仅身份已验证的 Desktop 可转接这种单个受管子空间请求；禁止主应用、管理空间、外来空间、未知状态、维护和过期服务纪元。关闭和重启经过现有非破坏性计划，并检查影响范围只有目标空间；正常停机失败不会再发启动。请求期间防重复，作业结果按原请求身份核对。展示消息通道没有增加管理授权。通用 Web 嵌入导航不变。
