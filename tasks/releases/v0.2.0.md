DSH Spaces 0.2.0 adds recoverable runtime upgrades, diagnostics, and a shared plugin library.

- Install and retain DSH versions, apply coordinated upgrades, and restore complete offline snapshots. Current data is backed up before restoration; damaged runtimes have an explicit data-only backup option.
- Inspect startup logs and restore configuration backups from the diagnostics panel. Space startup, restart, shutdown, and tray recovery are more reliable.
- Download plugins into a local library, then install them into selected spaces. Includes updated icons and appearance controls.
- Support DSH 0.1.5-rc.1 browser authentication and session APIs, while retaining compatibility with older snapshots. macOS builds now include the ZIP required by the updater.

Windows installation, embedded DSH pages, isolated sessions, upgrades, and snapshot recovery were tested with temporary data. macOS and Linux installers are built by CI; runtime behavior on those platforms was not tested in this release. Model generation and third-party plugin migrations were not exercised.

---

本版新增可恢复的 DSH 版本升级、完整快照、诊断和本地插件库，并修复恢复中断后的写入保护、运行时损坏时无法进入恢复页、恢复后保存旧设置，以及首次并发启动的依赖初始化问题。

恢复旧快照会撤销快照之后的配置和聊天；程序会先备份当前数据。恢复完成后空间保持停止，由用户决定何时启动。工作台之间隔离会话和存储，共享登录身份；会话隔离不是文件访问沙箱。
