# DSH Spaces 0.4.0

新增蓝图：将插件组合、配置预设和接收者需要填写的本机选项，保存成 JSON 或分享码。桌面和浏览器工作台都可以生成、复制、读取、预览和应用蓝图。使用说明见 [蓝图规范](https://github.com/klarkxy/dsh-spaces/blob/v0.4.0/BLUEPRINT.md)。

- 应用前核对插件来源、版本和完整性；填写本机目录或模型后创建新空间。创建完成不会自动启动。
- 重新生成时保留本机输入占位符，不把接收者的目录、模型连接或凭据复制进分享内容。蓝图与数据备份、迁移及旧 ZIP 分享保持独立。
- 修正模型桥的官方宿主加载、共享模型投影和插件卸载行为；拒绝用户配置占用共享模型保留名称，防止共享凭据随被改写的地址发送。
- 合入桌面正常启动修正：打开时连接已有服务，确认环境就绪且服务不存在时启动一次；首次安装后继续启动。真实故障仍只报告，不自动恢复。见 [#8](https://github.com/klarkxy/dsh-spaces/pull/8)。

蓝图 v1 支持 npm 来源；GitHub 来源暂不支持，会在写入前拒绝。Windows 已用隔离数据验证真实插件安装、模型目录、主题运行、浏览器与 Electron 流程，未发送真实模型推理请求。macOS 和 Linux 的运行交互未在本机验证。

本次发布提供桌面安装包，六个组件包同步版本；不执行 npm publish。桌面包未签名。
