# 2026-10-27 已打开空间快速切换

## 范围与结果

用户授权优化已打开且有效的空间切换，合并重复检查，保留必要的失效校验。

- Desktop 选择清单中运行的空间时直接进入展示链，不再经过启动操作的多次状态读取。停止或启动中的空间继续使用既有明确打开操作与正常生命周期检查。
- 已完成认证和握手、仍挂载且运行代次匹配的页面直接复用。Desktop 的代次提示经既有认证通道传递，工作台同时核对自己的状态、服务纪元和页面状态；提示只用于决定能否复用，不授予权限。
- 首次打开、代次不一致或没有可复用页面时，工作台读取一次当前状态，再申请入口并等待握手。没有代次提示的旧展示请求保留原有实时读取路径。
- 正常生命周期操作共用初始状态及完成状态，避免为生成返回清单再次读取。已运行空间的显式打开操作只读一次状态；启动成功路径保留初始和完成两次读取。
- 观察到停止、崩溃、删除、运行代次或服务纪元改变、Web 页面能力移除时，旧页面失效。已经失败或断开的页面不能通过快速切换重新连接。
- 并发状态读取保留已应用的新观察结果，不让迟到结果重新显示旧页面；切换读取不会中断后台失效检查。读取失败保留错误并停止后续读取，迟到轮询不能清除该错误。

已打开页面仍保留原节点和草稿。首次打开仍需要真实加载；本次没有预启动空间，也没有增加自动重试、重连、重启或失败任务续跑。
