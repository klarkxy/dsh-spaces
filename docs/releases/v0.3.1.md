DSH Spaces 0.3.1 unifies the desktop and browser workbench under one Supervisor.

Compatibility: the workbench uses protocol 2. Keep desktop and plugin components on the same version; older clients and stale mutation requests are rejected. Failed or interrupted work is reported and is not replayed or rolled back.

- Share spaces, plugins, model connections, templates, settings and jobs across both clients. Exiting the desktop leaves the service and its running jobs alive; stopping the service is a separate action.
- Verify component versions and file digests before upgrading. Confirm the handoff only after the new manager is ready.
- Fix first-start initialization being blocked by status polling, missing default snapshot directories, and automatic selection of browser-blocked ports.
- Preserve plugin archives referenced through Windows directory junctions while allowing unused versions to be removed.

Windows desktop/browser interaction, standard plugin installation, component handoff, runtime installation and normal snapshot management were exercised with disposable data. macOS and Linux runtime interaction was not tested locally. Desktop packages are unsigned. The `@dsh-spaces/*` packages remain unpublished on npm.

---

本版将桌面、浏览器和插件入口统一到同一个 Supervisor，共享空间、插件、模型连接、模板、设置与任务。退出桌面后，后台任务继续执行；停止服务需要单独操作。

组件升级先核验版本和文件摘要，新管理器就绪后才确认交接。修复首次启动时的状态轮询阻塞、默认快照目录缺失、浏览器禁止端口，以及目录联接导致仍被引用的插件归档被误删。

工作台协议升级为 2，桌面与插件组件应保持同一版本。旧客户端和过期变更会被拒绝，失败任务不会重放或回滚。

详细验证范围见 [合并验收记录](https://github.com/klarkxy/dsh-spaces/blob/v0.3.1/tasks/merge-execution.md)。
