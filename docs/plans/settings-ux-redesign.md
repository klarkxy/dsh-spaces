## 1. 现状结论

设置页按「后端模块」而不是「用户要做的事」组织。10 个并列 tab 里，用户每天用的只有空间和模型；其余是运维概念（运行时、快照、状态与任务、高级）和三套重叠的「复制空间」机制（蓝图、模板、分享导入）。同一个动作散在 3–4 处，有的动作又只藏在一处。

## 2. 设计原则

1. **按任务分组**：先回答「我想用哪个空间、给它装什么、接哪个模型」，运维信息收进维护区。
2. **每个空间一个详情页**：空间相关的所有动作只有一个权威位置；右键菜单只是快捷方式，不能是唯一入口。
3. **一个概念一个名字**：对用户只讲「空间」「插件」「模型连接」「空间模板」「备份」；内部术语（运行时、蓝图 v1/v2、目录 id、协议、代数）只在维护区或折叠的「详细信息」里出现。
4. **错误就近显示，且第一帧可见**：控件旁显示与它相关的失败；顶部横幅只留全局状态（只读、维护中、服务不可用）。继续遵守 let it crash：不加重试、修复、恢复按钮。
5. **确认弹窗按风险分级**，而不是每个写操作都弹（见第 6 节决策 D1）。
6. **空状态带下一步**：每个空列表给一个主按钮。

## 3. 目标信息架构

设置左侧导航从 10 个并列 tab 改为 4 个主分组 + 1 个折叠的维护组：

```
空间            空间列表 + 新建；点进去是空间详情页
空间模板        模板 / 蓝图 / 分享文件 统一入口：从模板创建、导入、把空间导出成模板
模型与连接      连接列表与新建向导；全局默认模型
常规            语言、主题
── 维护（默认折叠）──
状态与任务      服务状态（人话）、任务列表、日志
备份            整 Home 快照（原「快照」）
DSH 版本        已安装运行时与删除（原「运行时」）
服务            端口、包来源、目录地址；停止整个服务
```

**空间详情页**（替代现在的「诊断」对话框，从空间列表、右键菜单「管理…」、侧栏双击进入）：

| 区块 | 内容 | 来自 |
|---|---|---|
| 概览 | 名称、图标、状态；进入 / 启动 / 停止 / 重启 | 空间 tab 行、右键菜单 |
| 外观 | 重命名、更换图标（含头像库与上传） | 只在右键菜单的两项 |
| 插件 | 本空间已装插件；从目录搜索安装（版本下拉，默认最新兼容版）；升级 / 移除 | 插件 tab 第三段 |
| 模型 | 本空间使用的共享连接与默认模型 | 模型与连接 → 空间绑定 |
| DSH 版本 | 当前固定版本与切换 | 诊断对话框 |
| 诊断 | 进程状态、最近日志、复制脱敏日志 | 诊断对话框、状态与任务 |
| 导出 | 导出为空间模板 / 分享文件 | 模板 tab、右键「生成蓝图」 |
| 危险操作 | 删除空间 | 三处重复 |

插件 tab 的「目录 / 下载库」两段并入 空间模板 旁的「插件库」或详情页插件区的搜索，不再单独占一个顶级 tab（见决策 D3）。

**Desktop 外壳侧栏**：分割线下方空间列表末尾加「＋ 新建空间」按钮（直接打开创建对话框，不经过设置）。看板 ▦ 与设置 ⚙ 保持在底部。

## 4. 交互规则

- 创建空间成功后直接进入该空间（保留「已创建」提示作为状态，不再要求再点一次）。
- 文件导入统一换成可拖放的选择区，显示已选文件名与大小；JSON / 分享码粘贴框只在「高级」折叠里。
- 插件版本：目录返回的版本做下拉，默认最新兼容版；「精确版本」规则不变，只是由界面填好。
- 确认弹窗里一律显示空间显示名（id 作为次要文字）。
- 「状态与任务」把 job kind / status / phase 映射成中文短语，原始值放在可展开的「详细信息」里。
- 设置页整页模式铺满可用区域；弹窗模式保留尺寸上限。

## 6. 需要决策

- **D1 确认弹窗分级**：建议「启动 / 停止 / 重启 / 重命名 / 换图标」不弹确认（内部仍走预览 → 执行，后端预览若给出警告则照常弹出）；「删除空间、切换 DSH 版本、移除插件、创建或删除备份（会先停所有空间）、删除运行时、停止整个服务」保留确认。
- **D2 合并蓝图 / 模板 / 分享**：建议对用户统一叫「空间模板」，导入时自动识别分享文件、蓝图分享码、JSON；生成蓝图的 v1/v2、插件勾选等放进「导出为模板」的高级选项。底层三套格式不变。
- **D3 插件入口**：建议取消顶级「插件」tab，安装 / 升级 / 移除只在空间详情页；目录与下载库作为详情页里的搜索来源。若你常跨空间批量看插件，可保留一个只读的「插件库」。
- **D4 维护区可见性**：建议默认折叠但可见；不做开发者模式开关。
