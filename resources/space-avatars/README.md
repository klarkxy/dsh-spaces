# 空间头像

20 个普通空间预设头像，以及 desktop 专用的蓝发女仆头像。

- `desktop-maid.png`：根据用户补充参考图中间的蓝发女仆特征，绘制为同系列 Q 版头像；不进入普通空间选择器。
- 其余 20 个 PNG：普通空间选择器中的完整头像，按发色、发型、耳朵和配饰区分。
- `generation.json`：每张图的中文名、英文名及最终生成提示词。使用内置 ImageGen 逐张生成。
- `scripts/build-space-avatars.ps1`：从此目录原图生成 128 × 128 的界面用图片数据，写入 `src/shared/space-avatars.ts`。完整原图不进入运行时包。

选择预设后沿用现有 icon 图片字段保存，自定义上传保留。没有自定义头像的普通空间按空间 ID 显示稳定的预设头像。desktop 在原生空间栏固定为第一项，位于滚动列表之外。

2026-09-26 验证：相关单元检查、三套 TypeScript 类型检查及完整构建通过；隔离浏览器检查全部 20 个头像加载/选择、键盘选择、420px 宽度换列、滚动后 desktop 固定通过。既有浏览器回归 5 项通过（其中一条移除旧默认图标的断言后专项复跑通过）。本轮没有安装到真实 Home，也未把隔离浏览器组件验收记作官方 Desktop 实机验收。
